# FastBrowse — Packaged CLI

**Repo:** `~/Projects/fastbrowse` · **GitHub:** `StuBot69/fastbrowse` · **Commit:** `c91d0ec`
**Purpose:** eyes-first browser automation that sips tokens. Never sends DOM to an LLM.

## Quick start

```bash
cd ~/Projects/fastbrowse
./setup.sh                                                    # venv + playwright/camoufox/pillow + chromium
.venv/bin/python fb.py rules                                  # the 16 hard-won rules
.venv/bin/python fb.py hunt --ask "female cyborg" --site pixabay --out runs/demo
```

**Short version:** `QUICKSTART.md` in the repo root — setup, all 4 commands, vision endpoints, env vars, layout.

## Commands (`fb.py` — the only interface)

| command | what |
|---|---|
| `fb hunt --ask "..." [--site pixabay\|commons] [--verify "..."] [--out runs/NAME]` | eyes-first hunt + download + vision receipt |
| `fb replay --tape runs/NAME --href <url> [--ask ...]` | blind replay of a learned href (no hunt, hybrid gate) |
| `fb verify <file> --ask "..."` | eyes on a file: YES/NO + sentence |
| `fb sites` | learned site knowledge + stale flags |
| `fb rules` | the 16 hard-won rules |

## Vision endpoint (swappable, dual fallback)

Primary: Qwen2.5-VL-7B on llama.cpp over Tailscale (`http://100.95.162.99:8080`)
Fallback: Llama 3.2 11B Vision on Groq (free, 1M tokens/day)

Auto-fallback: if Jasper is down, Groq takes over. Groq key auto-loaded from age vault.

```bash
export FASTBROWSE_VISION_URL=http://<host>:8080/v1/chat/completions
export FASTBROWSE_VISION_MODEL=<model-id>
export FASTBROWSE_FALLBACK_URL=https://api.groq.com/openai/v1/chat/completions
export FASTBROWSE_FALLBACK_MODEL=llama-3.2-11b-vision-preview
```

No endpoint (or `FASTBROWSE_NO_VISION=1`) → hunt falls back to first-result, receipt reports `SKIP`. Nothing crashes.

## Layout

- `fb.py`, `fb_config.py`, `setup.sh`, `requirements.txt` — packaging
- `phase1/` measure · `phase2/` sentinel · `phase3/` site profiles
- `phase4/blind.py` — blind runner + hybrid drift gate
- `phase5/` — `grid_hunt.py`, `pixabay_suite.py`, `sydney_suite.py`, `learn.py`, `replay.py`, `sites/`, `runs/`
- `phase6/hover.py` — hover physics · `human_mouse.py` — Bezier mouse
- `REPORT.md` — full numbers + rules · `phase*/RESULTS.md` — per-phase

Run bulk (`profile/`, `downloads/`, raw `events.json`, browser binaries) is gitignored — reports + action maps are the memory.

## Key design

- **Zero metered LLM calls** — the browser loop makes no API calls. Only "tokens" are the ones you never spend.
- **Eyes-first hunting** — numbered badged thumbnails shown to a vision model, which picks. Never sends DOM to an LLM.
- **Blind replay** — learned href + TEXT gate (Jaccard ≥0.95) with dHash second opinion. Both fail = drift → `needs_relearn`.
- **Graceful degrade** — no vision endpoint → first-result fallback, receipt says SKIP.

## Rules (the 16)

1. Never send full DOM/AX to an LLM
2. Watch, don't snapshot — per-region dumb diffs at 2-4fps
3. One region changed → only that region goes up
4. Chronically noisy regions (ads, tickers, feeds) get quarantined
5. Dismiss overlays with count==1 visible guard — never a crowd
6. Blind replay: verify BY EFFECT, not by assertion
7. Two strikes blind → full snapshot, flag for re-profile
8. Learned hrefs are not exact URLs — session tokens, match by domain+path
9. Positional selectors (no stable attrs) — record, don't guess
10. Cloudflare "Just a moment..." kills vanilla Chromium — Camoufox walks through
11. Consent banners: reject, never accept
12. Lazy grids: scroll, settle, re-eval — never spend a look on 2 tiles
13. Pre-look overlay sweep: kill popups before spending a vision look
14. Layout-shift tripwire: skip wasted looks when fixed regions change
15. Pixabay Original races download+nav — fire-and-forget clicks, poll handler
16. Alt text lies — show numbered tiles to eyes first, download only what eyes verify
